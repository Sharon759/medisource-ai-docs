# MediSource AI — Documentation Site

This is a standalone MkDocs documentation project for the **MediSource AI — Hospital Procurement Intelligence Platform**.

## Quick Start

### 1. Install Requirements
```powershell
pip install mkdocs mkdocs-material
```

### 2. Live Preview Local Server
```powershell
python -m mkdocs serve
```
Then open [http://localhost:8000](http://localhost:8000) in your browser.

### 3. Build Static HTML
```powershell
python -m mkdocs build
```
Static production output will be generated into the `site/` directory.

### 4. Publish to GitHub Pages
```powershell
python -m mkdocs gh-deploy
```
